Comandos Git

Git Init


        git init - Inicializa repositório e mantém um histórico

Git Status


        git status - Podemos vizualizar o funcionamento correto do repositório

Git Add


        git add - Para preparar os arquivos da pasta
        git add nome_pasta ou arquivo
        git add .

Git Commit


        git commit - Irá enviar uma mensagem de confirmação para o GitHub
        git commit -m "Mensagem que desejo"

Git Log


        git log - Irá exibir o histórico de commits
        git log --oneline - Irá exibir o histórico de commits resumido

Git Branch


        git branch - Irá exibir as branches existentes
        git branch nome_da_branch - Irá criar uma nova branch
        git checkout nome_da_branch - Irá alternar para a branch especificada
        git branch -M main - Irá renomear a branch atual para main

Git Remote


        git remote - Irá exibir os remotos configurados
        git remote add origin url - Irá adicionar um novo remote
        git push origin main - Irá enviar alterações para o remote
        git remote add origin link_repositório
        git remote -v - Irá mostrar a URL configurada do origin

Git Push


        git push origin main - Irá enviar alterações para o remote
        git push -u origin main - Irá enviar alterações para o remote definir a branch atual como upstream
        git push - Enviar atualizações para o remote
